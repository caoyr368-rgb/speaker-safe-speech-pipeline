# Third-party model boundary

No third-party code or model weights are distributed in this repository. The links below are integration targets only.

| Project | Intended role | Upstream |
|---|---|---|
| pyannote segmentation 3.0 | overlap detection | https://huggingface.co/pyannote/segmentation-3.0 |
| TIGER | two-speaker separation | https://github.com/JusperLee/TIGER |
| ClearerVoice-Studio / MossFormerGAN | speech enhancement | https://github.com/modelscope/ClearerVoice-Studio |
| SenseVoice | wake candidate transcription | https://github.com/QwenAudio/SenseVoice |
| 3D-Speaker / CAM++ | primary speaker verification | https://github.com/modelscope/3D-Speaker |
| 3D-Speaker / ERes2NetV2 | secondary speaker verification | https://github.com/modelscope/3D-Speaker/tree/main/egs/voxceleb/sv-eres2netv2 |
| Qwen3-ASR | final command recognition | https://github.com/QwenLM/Qwen3-ASR |

Before redistribution or deployment, verify the current license of both the source code and the selected checkpoint. They may differ. Follow any attribution, access, acceptable-use, and distribution requirements published by the upstream maintainer or model host.
